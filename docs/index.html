Package overview

Calibrated Prediction-Powered Inference

Estimate a population mean using a small labeled sample and predictions on a larger unlabeled sample. ppi_aipw calibrates the predictions on the labeled outcomes, then computes an AIPW estimate with a standard error and confidence interval.

Use predictions from an existing model; no retraining is needed.

Quickstart R Package Open in Colab
  • Companion package: calibratedDML

Defaults

Estimator method="monotone_spline"
Confidence interval inference="wald"

Smooth monotone calibration with a Wald confidence interval.

Estimate a mean

from ppi_aipw import mean_inference

result = mean_inference(
    Y, Yhat, Yhat_unlabeled,
    method="monotone_spline",
    alpha=0.1,
)

estimate = result.pointestimate
standard_error = result.se
lower, upper = result.ci
print(result.summary())

Quickstart

Core inputs and defaults

Pass the outcomes and predictions to mean_inference(...). The result includes the estimate, standard error, confidence interval, fitted calibrator, and diagnostics.

For a runnable example, the quickstart notebook opens directly in Colab and covers both the mean and causal APIs.

For data-adaptive selection, set method="auto" and pass candidate_methods=("aipw", "linear", "monotone_spline", "isotonic"). Selection uses num_folds=100 by default, capped at the labeled sample size.

Use result.summary() for estimates, intervals, and p-values. Use calibration_diagnostics(result, Y, Yhat) for an optional out-of-fold calibration check.

Y

Observed outcomes for the labeled sample.

Yhat

Predictions on the same labeled rows.

Yhat_unlabeled

Predictions on the unlabeled sample.

method

Choose "aipw", "linear", "prognostic_linear", "sigmoid", "monotone_spline", "isotonic", or "auto".

cross_fit

Defaults to False. Set True to fit calibration, method selection, and efficiency scaling on training folds and evaluate on held-out observations from both samples.

calibration_folds

Number of honest calibration folds, default 10. Use len(Y) for leave-one-out labeled calibration when the unlabeled sample is larger.

candidate_methods

Candidate methods considered when method="auto" minimizes a cross-validated variance estimate. If "aipw" is included, the selector also compares a rescaled AIPW candidate.

num_folds

Number of folds used by method="auto". The default is 100 and it is capped at the labeled sample size.

inference

Choose "wald" for a fast analytic interval, "jackknife" for a V-fold jackknife interval with Student t critical values, or "bootstrap" for percentile bootstrap intervals.

efficiency_maximization

Optional rescaling to lambda m(X). For method="aipw", m(X) is the raw score; otherwise it is the calibrated score.

w, w_unlabeled

Optional observation weights for labeled and unlabeled samples. Uniform weights reproduce the unweighted estimator.

X, X_unlabeled

Optional extra covariates for method="prognostic_linear". The score and intercept are unpenalized; extra covariates use ridge tuning on the labeled sample.

Calibration

What calibration changes

A score can rank outcomes well while predicting values that are too high or too low.

Prediction

A calibrated score of 0.8 corresponds to an average outcome of 0.8. Calibration estimates this relationship from the labeled sample and adjusts the original predictions.

Inference

AIPW averages predictions over both samples and adds the average residual from the labeled sample. Calibrating the predictions can reduce the variability of those residuals and improve precision.

Methods

Choose a calibration method

Compare the fitted curves, assumptions, and options below.

Default

Monotone spline calibration

Fits a smooth nondecreasing curve to the labeled outcomes, then uses the calibrated predictions in AIPW. This is the default method.

Calibration Map

When to use it

    Tradeoffs

      Intervals

      Wald, jackknife, and bootstrap intervals

      Wald intervals use an analytic standard error. Jackknife and bootstrap intervals refit calibration. Jackknife uses jackknife_folds=10 and Student t critical values.

      Wald intervals

      Uses an analytic standard error and a normal approximation.
